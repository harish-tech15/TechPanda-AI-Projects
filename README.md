# TechPanda AI Projects

A collection of AI and Machine Learning projects developed during my TechPanda Generative AI training.

## Projects

### 1. ResearchMind AI
- Category: AI Chatbot
- A multi-agent research chatbot built using Python and Streamlit.

### 2. AutoPrep AI
- Category: Data Preprocessing
- A data preprocessing project using the IBM HR Employee Attrition dataset.

### 3. AttriPredict AI
- Category: Deep Learning
- Employee attrition prediction using an Artificial Neural Network (ANN).
- Includes standalone and integrated implementations.
- Uses the same IBM HR Employee Attrition dataset as AutoPrep AI.

## Integrated ANN Results

- Test Accuracy: 80.95%
- ROC-AUC: 0.7872
- Leave (Yes) Recall: 55%

These are experimental results on the test dataset. The model is developed for educational purposes and should not be used as the sole basis for HR decisions.
