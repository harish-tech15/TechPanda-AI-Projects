# AttriPredict AI

An employee attrition prediction project using an Artificial Neural Network (ANN) built with TensorFlow and Keras.

## Project Implementations

1. Standalone ANN prediction implementation.
2. Integrated end-to-end implementation combining data preprocessing and ANN prediction.

## Dataset

IBM HR Employee Attrition dataset.

The same dataset is used in AutoPrep AI and AttriPredict AI.

## Integrated Model Results

- Test Accuracy: 80.95%
- ROC-AUC: 0.7872
- Leave (Yes) Recall: 55%

## Technologies

Python | Pandas | NumPy | Scikit-learn | TensorFlow | Keras
